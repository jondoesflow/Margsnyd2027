# New Year's Day Lunch Pre-order (Margherita's, Deal)

A static page where each family party picks dishes per person from the Margherita's menu and emails the pre-order to jon@jondoesflow.com.

- Lunch: Friday 1 January 2027, 12pm
- Pre-order deadline: Tuesday 1 December 2026

Files: `index.html` (page and logic) and `menu.js` (menu transcribed from the restaurant's PDF). No build step, so it can be hosted on GitHub Pages or Netlify as is.
